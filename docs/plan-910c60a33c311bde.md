## tsconfig.json (key options)
- Environment: `target: es2025`, `lib: ["es2025"]` (no DOM), `types: []` (no @types/node), `module: esnext`, `moduleResolution: bundler`, `moduleDetection: force`, `verbatimModuleSyntax`, `rewriteRelativeImportExtensions` (write `./x.ts`, emit `./x.js` valid in any ESM runtime), `erasableSyntaxOnly` (no enums/namespaces/parameter properties — pure type-erasure TS), `allowJs: false`, `checkJs: false`, `resolveJsonModule: false`.
- Strictness: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitReturns`, `noImplicitOverride`, `noFallthroughCasesInSwitch`, `noPropertyAccessFromIndexSignature`, `noUnusedLocals`, `noUnusedParameters`, `allowUnreachableCode: false`, `allowUnusedLabels: false`, `noUncheckedSideEffectImports`, `forceConsistentCasingInFileNames`, `isolatedDeclarations` (forces explicit types on exports), `skipLibCheck: false`, `noErrorTruncation`.
- Emit: `rootDir: src`, `outDir: dist`, `declaration`, `declarationMap`, `sourceMap`, `noEmitOnError`, `newLine: lf`.
- Evaluated & documented but not enabled (or left default): `stableTypeOrdering` (migration aid), `libReplacement`, `allowImportingTsExtensions` (requires noEmit), `module: nodenext/preserve`, `importHelpers`, `composite`.

## eslint.config.js (flat config, `defineConfig` from `eslint/config`)
- `js.configs.recommended` + `tseslint.configs.strictTypeChecked` + `tseslint.configs.stylisticTypeChecked`; `parserOptions.projectService: true`, `tsconfigRootDir: import.meta.dirname`; `disableTypeChecked` for `*.js` config files; ignore `dist/`.
- `linterOptions`: `noInlineConfig: true` (no `eslint-disable` escape hatch), `reportUnusedDisableDirectives: "error"`.
- Explicit intent: `explicit-function-return-type`, `explicit-module-boundary-types`, `explicit-member-accessibility`, `no-inferrable-types: off` (conflicts with goal), core `no-restricted-syntax` selectors requiring annotations on variable declarators, function/arrow params, class properties, and destructuring (with clear messages; exceptions e.g. `for...of` documented).
- Escape hatches: `no-explicit-any`, all `no-unsafe-*`, `no-unsafe-type-assertion`, `consistent-type-assertions` (`objectLiteralTypeAssertions: never`), `no-non-null-assertion`, `ban-ts-comment` (ban ts-ignore/ts-nocheck/ts-check; ts-expect-error only with description), `prefer-ts-expect-error`.
- Correctness: `strict-boolean-expressions`, `switch-exhaustiveness-check`, `no-unnecessary-condition`, `no-floating-promises`, `no-misused-promises`, `only-throw-error`, `prefer-promise-reject-errors`, `use-unknown-in-catch-callback-variable`, `require-array-sort-compare`, `no-deprecated`, `consistent-type-imports/exports`, `prefer-readonly`, `promise-function-async`, `naming-convention` (camelCase/PascalCase/UPPER_CASE), `no-shadow`, `no-use-before-define`, `default-param-last`.
- Core: `eqeqeq`, `curly: all`, `no-var`, `prefer-const`, `no-param-reassign`, `no-implicit-coercion`, `no-eval`, `no-new-wrappers`, `no-throw-literal`→ts version, `no-unused-vars` off in favor of compiler/TS rule (dedupe decision documented).
- Considered but rejected (documented): `typedef` (deprecated), `prefer-readonly-parameter-types` (very noisy), `no-magic-numbers`, `init-declarations`, `member-ordering`, `sort-type-constituents`, `no-type-alias`, `max-params`, framework/plugin rules (import, unicorn, etc.).

## Risks / limitations
- Not on TS 7 (native) due to typescript-eslint; documented upgrade path.
- `no-restricted-syntax` annotation selectors are AST-based, not type-aware; edge cases (callbacks, `for...of`, catch clauses) documented.
- `noInlineConfig` means no per-line lint escape at all — intentional, documented how to change.
- `erasableSyntaxOnly` bans enums/namespaces — intentional, documented alternative (`as const` objects / unions).
