# 10. Rules reference

Every important rule enforced by the project. Examples in the **Example** column are intentionally
invalid; their purpose is to demonstrate the rule. **Result** is what you see when the example is
placed in `src/`.

Rule prefixes: `TS` = compiler (`tsconfig.json`), `@ts-eslint/` = typescript-eslint, no prefix =
ESLint core. Rules marked † are configured explicitly in `eslint.config.js`; the rest come from the
`strictTypeChecked` / `stylisticTypeChecked` / `js.configs.recommended` presets.

## A. Compiler rules

Detailed explanations: [compiler-options.md](compiler-options.md).

| Name                                    | Category            | Reason                       | Example                                       | Result                       |
| --------------------------------------- | ------------------- | ---------------------------- | --------------------------------------------- | ---------------------------- |
| `strict` (family)                       | Type safety         | Baseline soundness           | `function f(x) {}`                            | TS7006 implicit any          |
| `noUncheckedIndexedAccess`              | Null safety         | Index may be missing         | `const n: number = arr[0];`                   | TS2322 `number \| undefined` |
| `exactOptionalPropertyTypes`            | Null safety         | Absent ≠ `undefined`         | `const p: { a?: string } = { a: undefined };` | TS2375                       |
| `noPropertyAccessFromIndexSignature`    | Explicitness        | Dynamic keys look dynamic    | `record.key`                                  | TS4111                       |
| `noImplicitReturns`                     | Control flow        | Every path returns           | missing `return` in a branch                  | TS7030 / TS2366              |
| `noImplicitOverride`                    | Explicitness        | Overrides are deliberate     | method shadows base without `override`        | TS4114                       |
| `noFallthroughCasesInSwitch`            | Control flow        | No accidental fallthrough    | `case 1: x = 1; case 2:`                      | TS7029                       |
| `noUnusedLocals` / `noUnusedParameters` | Dead code           | Unused = bug or noise        | `const x: number = 1;` unused                 | TS6133                       |
| `allowUnreachableCode: false`           | Dead code           | Code after `return`          | `return; foo();`                              | TS7027                       |
| `allowUnusedLabels: false`              | Confusing construct | Mistyped object literal      | `() => { value: 1 }`                          | TS7028                       |
| `isolatedDeclarations`                  | Module boundaries   | Exports are self-describing  | `export function f(a: number) { return a; }`  | TS9007                       |
| `verbatimModuleSyntax`                  | Module syntax       | Type imports are explicit    | `import { SomeType } from "./t.ts";`          | TS1484                       |
| `erasableSyntaxOnly`                    | Pure TypeScript     | Types only, no runtime TS    | `enum Color { Red }`                          | TS1294                       |
| `noUncheckedSideEffectImports`          | Module syntax       | Typos in side-effect imports | `import "./mising.ts";`                       | TS2882                       |
| `lib: ["es2025"]`, `types: []`          | Environment         | Language only                | `console.log(1);`                             | TS2584                       |

## B. Explicit typing (lint)

| Name                                          | Category          | Reason                      | Example                        | Result                                             |
| --------------------------------------------- | ----------------- | --------------------------- | ------------------------------ | -------------------------------------------------- |
| `no-restricted-syntax` † (variables)          | Explicit typing   | State intent                | `const name = "Sanjay";`       | "Explicit type required: annotate the variable"    |
| `no-restricted-syntax` † (parameters)         | Explicit typing   | State intent                | `[1].map((n) => n)`            | "annotate every function parameter"                |
| `no-restricted-syntax` † (defaults)           | Explicit typing   | Default ≠ declared type     | `function f(n = 1): number`    | "annotate parameters that have default values"     |
| `no-restricted-syntax` † (destructured/rest)  | Explicit typing   | State intent                | `function f(...rest): void`    | "annotate destructured and rest parameters"        |
| `no-restricted-syntax` † (class properties)   | Explicit typing   | State intent                | `class A { public n = 0; }`    | "annotate every class property"                    |
| `@ts-eslint/explicit-function-return-type` †  | Explicit typing   | Return type is a contract   | `const id = (n: number) => n;` | "Missing return type on function"                  |
| `@ts-eslint/explicit-module-boundary-types` † | Module boundaries | Exports are contracts       | `export function f(x: any)`    | "Argument 'x' should be typed with a non-any type" |
| `@ts-eslint/explicit-member-accessibility` †  | Explicitness      | Visibility is a decision    | `class A { run(): void {} }`   | "Missing accessibility modifier"                   |
| `@ts-eslint/no-inferrable-types` † **off**    | —                 | Contradicts explicit typing | —                              | —                                                  |

## D. Correctness the compiler cannot check

| Name                                                                                                                                                       | Category               | Reason                                                           | Example                                                     | Result                                                  |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------------- |
| `@ts-eslint/strict-boolean-expressions` †                                                                                                                  | Unnecessary/confusing  | Truthiness hides `0`/`""`/`null` cases                           | `if (name) {}` with `name: string`                          | "Unexpected string value in conditional"                |
| `@ts-eslint/switch-exhaustiveness-check` †                                                                                                                 | Exhaustiveness         | Every union member handled                                       | `switch (shape) { case "circle": }`                         | "Switch is not exhaustive"                              |
| `@ts-eslint/no-unnecessary-condition`                                                                                                                      | Unnecessary constructs | Condition always true/false                                      | `if (n !== undefined)` for `n: number`                      | "Unnecessary conditional"                               |
| `@ts-eslint/no-unnecessary-boolean-literal-compare`, `-template-expression`, `-type-arguments`, `-type-constraint`, `-type-conversion`, `-type-parameters` | Unnecessary constructs | Noise                                                            | `` `${text}` `` for string                                  | reported                                                |
| `@ts-eslint/no-floating-promises`                                                                                                                          | Promises               | Unhandled rejections                                             | `Promise.resolve(1);`                                       | "Promises must be awaited…"                             |
| `@ts-eslint/no-misused-promises`, `await-thenable`, `return-await`, `require-await`                                                                        | Promises               | Promise misuse                                                   | `await 1;`                                                  | reported                                                |
| `@ts-eslint/promise-function-async` †                                                                                                                      | Promises               | Promise-returning functions are `async`                          | `function f(): Promise<void> { return Promise.resolve(); }` | "Functions that return promises must be async"          |
| `@ts-eslint/only-throw-error`                                                                                                                              | Error handling         | Only `Error` objects carry stacks                                | `throw "bad";`                                              | "Expected an error object to be thrown"                 |
| `@ts-eslint/prefer-promise-reject-errors`                                                                                                                  | Error handling         | Same for rejections                                              | `Promise.reject("bad")`                                     | reported                                                |
| `@ts-eslint/use-unknown-in-catch-callback-variable`                                                                                                        | Error handling         | `.catch((e) => …)` is `unknown`                                  | `.catch((e: any) => {})`                                    | reported                                                |
| `@ts-eslint/restrict-plus-operands`, `restrict-template-expressions`, `no-base-to-string`                                                                  | Confusing constructs   | Accidental string coercion                                       | `` `${{}}` ``                                               | reported                                                |
| `@ts-eslint/no-confusing-void-expression`, `no-meaningless-void-operator`, `no-invalid-void-type`                                                          | Confusing constructs   | `void` misuse                                                    | `const x: void = f();`                                      | reported                                                |
| `@ts-eslint/require-array-sort-compare` †                                                                                                                  | Confusing constructs   | Default sort is lexicographic                                    | `[10, 2].sort()`                                            | "Require 'compare' argument"                            |

| `@ts-eslint/unbound-method`                                                                                                                                | Confusing constructs   | Lost `this`                                                      | `const f = obj.method;`                                     | reported                                                |
| `@ts-eslint/no-deprecated`                                                                                                                                 | Deprecated features    | Avoid `@deprecated` APIs                                         | `"a".substr(0)`                                             | "`substr` is deprecated"                                |
| `@ts-eslint/no-namespace`, `prefer-namespace-keyword`, `triple-slash-reference`, `no-require-imports`                                                      | Deprecated/legacy TS   | Modern modules only                                              | `namespace N {}`                                            | reported                                                |
| `@ts-eslint/no-unused-vars` †                                                                                                                              | Unused code            | Also catches unused `catch` bindings, type params; no `_` escape | `catch (error) {}` unused                                   | "'error' is defined but never used"                     |
| `@ts-eslint/no-shadow` †                                                                                                                                   | Confusing constructs   | Shadowing hides bugs                                             | inner `const x` shadows outer `x`                           | reported                                                |
| `@ts-eslint/no-use-before-define` †                                                                                                                        | Confusing constructs   | Temporal dead zone                                               | use before `const`                                          | reported                                                |
| `@ts-eslint/default-param-last` †                                                                                                                          | Confusing constructs   | Defaults before required params are useless                      | `function f(a: number = 1, b: number)`                      | reported                                                |
| `@ts-eslint/prefer-readonly` †                                                                                                                             | Explicit intent        | Private members never reassigned should be `readonly`            | `private x: number = 1;`                                    | "Member 'x' is never reassigned"                        |
| `@ts-eslint/consistent-type-imports` †, `consistent-type-exports` †, `no-import-type-side-effects` †                                                       | Module syntax          | Type-only imports are visible                                    | `import { T } from …` (type only)                           | reported                                                |
| `@ts-eslint/method-signature-style` †                                                                                                                      | Function variance      | Method shorthand in types is bivariant                           | `interface A { f(x: string): void }`                        | "Shorthand method signature is forbidden"               |
| `@ts-eslint/naming-convention` †                                                                                                                           | Naming                 | Consistent names                                                 | `const My_value: number = 1;`                               | "Variable name must match one of the following formats" |

`naming-convention` policy: default `camelCase`; `const` variables `camelCase` or `UPPER_CASE`;
imports `camelCase`/`PascalCase`; types, interfaces, classes, type parameters `PascalCase`; no
leading/trailing underscores; quoted object keys exempt.

## E. Stylistic consistency (typescript-eslint `stylisticTypeChecked`)

`array-type` (`T[]`), `consistent-type-definitions` (`interface`), `consistent-indexed-object-style`
(`Record`), `consistent-generic-constructors`, `prefer-nullish-coalescing` (`??` over `||`),
`prefer-optional-chain`, `prefer-for-of`, `prefer-includes`, `prefer-find`,
`prefer-string-starts-ends-with`, `prefer-regexp-exec`, `prefer-function-type`, `dot-notation`
(respects `noPropertyAccessFromIndexSignature`), `no-empty-function`, `class-literal-property-style`,
`adjacent-overload-signatures`, `non-nullable-type-assertion-style`.

## F. ESLint core rules

| Name                                                             | Category             | Reason                                           | Example                                   | Result                  |
| ---------------------------------------------------------------- | -------------------- | ------------------------------------------------ | ----------------------------------------- | ----------------------- |
| `eqeqeq` †                                                       | Confusing constructs | `==` coerces                                     | `a == b`                                  | "Expected '==='"        |
| `curly` † `all`                                                  | Confusing constructs | No brace-less bodies                             | `if (a) b();`                             | "Expected { after 'if'" |
| `no-var`                                                         | Legacy               | Block scoping                                    | `var x: number = 1;`                      | "Unexpected var"        |
| `prefer-const`                                                   | Explicit intent      | Not reassigned → `const`                         | `let x: number = 1;` never reassigned     | reported                |
| `no-param-reassign` † (`props: true`)                            | Confusing constructs | Parameters are inputs                            | `n = 2;` inside function                  | reported                |
| `no-implicit-coercion` †                                         | Explicit intent      | Write `Number(x)`, not `+x`                      | `!!value`                                 | reported                |
| `no-new-wrappers` †                                              | Confusing constructs | `new String()` objects                           | `new Number(1)`                           | reported                |
| `no-eval` †                                                      | Security             | Dynamic code                                     | `eval("1")`                               | reported                |
| `no-console` †                                                   | Environment          | `console` is a host API (also absent from `lib`) | `console.log(1)`                          | reported                |
| `no-else-return` †, `no-lonely-if` †, `no-nested-ternary` †      | Readability          | Flatter control flow                             | `if (a) { return 1; } else { return 2; }` | reported                |
| `object-shorthand` †, `no-useless-rename` †, `prefer-template` † | Consistency          | One way to write it                              | `{ a: a }`                                | reported                |
| `radix` †                                                        | Confusing constructs | `parseInt` radix                                 | `parseInt("8")`                           | reported                |
| `prefer-rest-params`, `prefer-spread` + `js.configs.recommended` | Correctness          | Core bug rules                                   | `arguments`                               | reported                |
